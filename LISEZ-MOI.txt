RED OSINT — Module Recherche par identité
===========================================

Fichier : recherche-identite.html

Installation simple
-------------------
1. Ouvre ton dépôt GitHub `red-osent`.
2. Clique sur Add file > Upload files.
3. Glisse `recherche-identite.html` à la racine du dépôt.
4. Clique sur Commit changes.
5. Après le déploiement GitHub Pages, ouvre :
   https://r29yj2d4cf-pixel.github.io/red-osent/recherche-identite.html

Important
---------
Ce module est autonome : il ne remplace aucun fichier existant.
Il prépare des recherches portant sur des informations professionnelles
ou institutionnelles publiques. La date de naissance saisie reste locale
dans le formulaire et n'est jamais incluse dans les recherches externes.

Pour l'ajouter au menu de la page principale, il faudra ensuite modifier
le lien de navigation dans `index.html` pour pointer vers :
`recherche-identite.html`
