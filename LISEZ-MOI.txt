RED OSINT — MULTISEARCH

Installation :
1. Ouvre ton dépôt GitHub red-osent.
2. Clique sur Add file > Upload files.
3. Dépose multisearch.html à la racine du dépôt.
4. Clique sur Commit changes.

Après publication, le module sera disponible à :
https://r29yj2d4cf-pixel.github.io/red-osent/multisearch.html

Pour ajouter un lien depuis la page d'accueil, ajoute un lien vers :
multisearch.html

Ce module lance des recherches externes sur des sources professionnelles et institutionnelles publiques.
Il ne collecte pas automatiquement les résultats et ne recherche pas de données privées.
